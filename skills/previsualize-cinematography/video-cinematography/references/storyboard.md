# 分镜脚本模板与填写说明

## 基础分镜格式

```
┌─────────────────────────────────────────────────────┐
│ 场景编号: ___  场景名称: ________________________   │
│ 地点: ________________  时间: ___________________  │
├────┬──────┬────────┬──────────┬────────┬───────────┤
│镜号│ 景别 │ 运镜   │ 机位/角度 │ 时长   │ 画面描述   │
├────┼──────┼────────┼──────────┼────────┼───────────┤
│ 1  │      │        │          │        │           │
│ 2  │      │        │          │        │           │
└────┴──────┴────────┴──────────┴────────┴───────────┘
备注：_____________________________________________
```

---

## 字段填写指南

### 景别（按从小到大）
- **ECU** 大特写（眼睛/局部细节）
- **CU** 特写（面部）
- **MCU** 中近景（胸口以上）
- **MS** 中景（腰部以上）
- **MWS** 中全景（膝盖以上或完整关系动作）
- **WS** 远景（人物全身+环境）
- **EWS** 极远景（空旷环境）

默认从 `MCU/CU/ECU` 中选择最紧且信息完整的景别。`MWS/WS/EWS` 只用于
剧情必须看清的入场、离场、穿越、靠近、退开、换位、交接落点或其他有后果的
位置变化。宽景别行必须写
`position-change exception: 起点 -> 路径 -> 落点 -> 关系变化 -> 随后的特写对象`，
并只保留最短可读时长。场景开头、环境/尺度、角色仍在场、对白开始、连续性证明
或生成 Segment 切换，都不构成使用全景的理由。

### 运镜类型
- `固定` 机身不动
- `推` 向前推进
- `拉` 向后拉远
- `摇` 水平旋转
- `移` 横向/纵向移动
- `跟` 跟随主体
- `升降` 上下运动
- `俯仰` 垂直旋转
- `环绕` 圆周运动
- `手持` 随机抖动
- `组合` 两种以上运镜

### 机位/角度
- `平视` 与主体等高
- `仰拍` 低于主体，向上拍
- `俯拍` 高于主体，向下拍
- `侧拍` 90°侧面
- `背面` 从背后拍
- `斜侧` 45°侧面

### 时长参考
- 过渡镜头：1-3秒
- 正常叙事：3-8秒
- 特写强调：1-3秒
- 全景位置变化例外：只保留从起点到落点的最短可读时长
- 情绪镜头：8秒以上

## 完整分镜示例

```
场景: 咖啡馆邂逅
总时长: 约45秒

┌─────────────────────────────────────────────────────┐
│ 场景编号: 03  场景名称: 咖啡馆邂逅                   │
│ 地点: 咖啡馆内  时间: 下午                          │
├────┬──────┬────────┬──────────┬────────┬───────────┤
│ 1  │ ECU  │ 固定   │ 斜侧     │ 2秒    │ 指尖压住书页│
│    │      │        │          │        │ 忽然停住   │
├────┼──────┼────────┼──────────┼────────┼───────────┤
│ 2  │ CU   │ 固定   │ 平视     │ 3秒    │ 她抬眼望向  │
│    │      │        │          │        │ 画外门铃声 │
├────┼──────┼────────┼──────────┼────────┼───────────┤
│ 3  │ MS   │ 移     │ 斜侧     │ 4秒    │ 男子穿过前景│
│    │      │        │          │        │ 落在她对面 │
├────┼──────┼────────┼──────────┼────────┼───────────┤
│ 4  │ CU   │ 固定   │ 平视     │ 3秒    │ 男子认出她，│
│    │      │        │          │        │ 呼吸一停   │
├────┼──────┼────────┼──────────┼────────┼───────────┤
│ 5  │ ECU  │ 固定   │ 平视     │ 2秒    │ 她眼神微变，│
│    │      │        │          │        │ 书页仍未翻动│
└────┴──────┴────────┴──────────┴────────┴───────────┘

备注：门铃、视线方向与男子穿过前景共同建立空间，不先展示咖啡馆全貌；
     关系动作短暂放到中景，决定性的认出与回应交给特写，全片无台词。
     两人落位后固定她在银幕左侧看右、他在银幕右侧看左，机位留在门窗一侧，
     正反打不越轴。
```

## 快速检查清单

在完成分镜后，逐项检查：

- [ ] 每个镜头有明确的叙事目的
- [ ] 景别变化有逻辑（避免跳切）
- [ ] 运镜速度与情绪匹配
- [ ] 起幅和落幅画面稳定
- [ ] 总时长符合实际需求
- [ ] 剪辑节奏有呼吸感（不是一直快）
- [ ] 关键脸部、反应、手/爪、伤口、线索或教学细节得到特写
- [ ] 每个互动段都写明 A/B 银幕左右、相反看向、对视轴与机位轴侧
- [ ] 每个 MWS/WS/EWS 都标出剧情必需的位置变化、起点、路径、落点和紧景别回归
- [ ] ECU/CU/MCU 数量多于其他景别总和
- [ ] 没有连续退回全员同框，也没有正面横排的舞台化构图
