# Narrated Fable Drama · 阿语寓言解说剧

[English](README.en.md) · **中文**

> 把一篇你写的普通故事，自动制作成最长 **240 秒、16:9** 的阿语 AI 解说剧或寓言短片。

你不需要任何影视基础——**不用懂运镜、构图、灯光、剪辑、配音或导演方法**。
你只负责讲清楚故事，专业的镜头语言、表演节奏、声音和成片流程全部由项目自动完成。

---

## 你只需要做三件事

1. **写故事** —— 用日常语言写下你的故事，或直接在对话里讲出来；
2. **说国家** —— 说明目标国家（用于确定语言与文化语境）；
3. **看片段** —— 在每个片段生成后看一眼，决定「接受 / 重做 / 暂停」。

> 其余专业环节——改写阿语剧本、设计角色与场景、规划镜头、让 Seedance 生成
> 画面、口型、临时人物声和原生环境/动作声，再逐段切除全部人物声并立即嵌入
> ElevenLabs 精确阿语对白，并用无对白的 Seedance 原生声修补替换窗口、
> 逐段质检、修复接缝、精确字幕、导出成片——都由项目按内置的电影制作规范自动处理。

---

## 它适合什么故事

- 人物、动物、幻想角色、拟人化物体或混合角色；
- 外部旁白；
- 普通角色对白；
- 角色在画内说话后，以同一个声音转为画外讲述；
- 现实框架戏引出嵌套寓言，再返回框架戏；
- 同一段中切换角色对白、画内讲述和画外讲述，并保持同一角色声音连续。

## 成片规格

> 缺省值已经能出优质成片，你不用记；只有想调整时，才在对话里说一句即可。

| 项目         | 规则                                        |
| :----------- | :------------------------------------------ |
| 你要提供的   | 一篇故事 + 目标国家                         |
| 画幅         | 固定 `16:9`（横屏）                         |
| 视觉风格     | 缺省「3D 治愈动画」，可在对话中指定其他风格 |
| 分辨率       | 缺省 `1080p`，可选 `480p` / `720p` / `1080p` / `4K` |
| 最长总时长   | `240` 秒                                    |
| 语言         | 固定阿拉伯语；目标国家用于方言自然度与文化语境 |
| 声音         | Seedance 生成临时人物声和全部原生环境/动作声；每段立即切除人物声，以无对白的 Seedance 原生声修补切口，再换入 ElevenLabs 精确阿语；ElevenLabs 只生成对白 |
| 字幕         | 自动生成外挂与烧录字幕，画面里不会硬塞文字  |

## 大致流程

```text
你的故事 + 目标国家
        │
        ▼
项目自动：改写阿语剧本 → 设计角色与场景 → 规划镜头
        → 独立审计每段 Seedance 指令
        → 每段 Seedance 生成画面、口型、临时人物声和原生环境/动作声
        ├─ 画面轨：立即审查画面；通过后可另行确认并生成下一段画面
        └─ 音频轨：立即切除人物声，保留 Seedance 环境/动作声，只嵌入 ElevenLabs 阿语对白
        │
        ▼
完整音画审查：当前段配音通过后 → 接受 / 重做 / 暂停   ← 你在这里参与
        │
        ▼
项目自动：统一剪辑 → 修复接缝 → 加字幕 → 导出成片
```

整个流水线由系统自动跑完，**你只在「逐段确认」这一步参与**：看一眼片段，
再决定接受还是重做。

## 你和项目怎么配合

在正式开始生成视频前，项目会自动完成前期的剧本、设计和镜头规划。通常只在以下
情况暂停来问你：

- 缺少目标国家；
- 有重要的创作选择无法替你安全决定；
- 即将覆盖你已有的内容。

进入视频生成后，是这样一个循环：

1. 项目展示某一段的生成摘要；
2. 你确认「只生成这一段一次」；
3. 项目生成画面并立即审查；画面通过后，下一段画面可在你另行确认后开始，
   不必等待当前段配音完成；
4. 当前段同时完成阿语对白替换和完整音画审查；你再选择接受、修改后重做、
   原样重试或暂停；
5. 全部片段接受后，你再确认最终成片方案。

> **重要：** 项目绝不会背着你批量生成或自动重试——每一次视频生成都需要你当场
> 授权一次。

## 核心特性

这是产品最值钱的地方，也是它和「随手 AI 生成一段视频」的根本区别。你**完全不用
懂、不用设置**，系统在背后替你执行专业剧组的镜头调度和质量把关。

### 一、电影级镜头语言（自动运镜与调度）

系统不是随机拼画面，而是按一套统一的电影视觉语法来讲你的故事，让成片有「导演
拍出来」的观感：

| 能力           | 说明                                                         |
| :------------- | :----------------------------------------------------------- |
| 少人同框       | 默认只让必要角色出现在画面里，避免一堆人挤在一起、不知道该看谁 |
| 近景为主的表演 | 以特写 / 近景 / 中近景为主，抓住眼神、表情、嘴型和关键动作     |
| 视线与轴线连贯 | 谁看向谁、谁在左谁在右始终一致（即「对视轴 / 正反打」），对话不穿帮 |
| 克制用大景别   | 只有剧情需要交代「谁走到哪里、位置变了」时才短暂拉远，随即回到细节 |
| 画外角色不断线 | 角色被裁到画面外，仍通过视线、声音、前景和后续反应保持空间连续 |

> **你的收益：** 不学任何运镜、构图、剪辑知识，也能得到镜头讲究、视线连贯、
> 情绪到位的成片。

### 二、全程自动质检与纠错（四道关卡守住质量）

系统在关键节点自动「查验收」，任何一关不通过就**不允许流程往下走**，从源头挡住
常见的 AI 视频翻车问题：

1. **剧本关** —— 检查每句台词在所在镜头时长里能否自然说完，避免「语速像吵架」
   「字幕追不上」。硬性上限：中文每秒不超过 **4 个字**、英文等每秒不超过
   **2.6 个词**，且每句都留起止呼吸余量。
2. **镜头关** —— 检查分镜是否符合上面的镜头语言（少人同框、近景主导、视线轴线
   正确、大景别只在必要时出现），并逐段核对台词、说话人和口型。
3. **成片指令关** —— 真正生成视频前，一次性复核所有片段的镜头顺序、景别、精确
   台词和该排除的元素，确保交给生成的是一份完整、自洽的「拍摄说明」。
4. **独立提示审计关** —— 由制片部门内部独立门禁核对三段式结构、八个核心要素、素材
   可读映射、每镜唯一主运镜、防畸变兜底以及“Seedance 提供原生环境/动作声和
   临时人物声，后期只用 ElevenLabs 替换为精确阿语对白”的音频归属；
   指令或分镜一旦变化，旧 PASS 自动失效。

此外，每个片段先独立审查画面；画面通过即可作为下一段的连续性依据。当前段完成
阿语对白替换后，再**完整看一遍正常速度、带声音的成片**，逐项核对：

- 精确台词是否只出现一次，是否由正确角色说出；
- 只有当前画内说话人的嘴在说话；
- 角色从画内转画外时是否仍是同一个声音；
- 嵌套寓言里是否误出现框架讲述者、画像、倒影或剪影；
- 身份、服装、道具、空间、灯光、色彩、阿语配音和动作阶段是否连续；
- 对视方向和正反打是否保持同一轴侧；
- 是否保持近景主导，宽景是否只服务于必要的位置变化；
- 是否出现多余角色、重复人物、字幕、Logo、水印、截断语音或回放尾帧。

发现问题会明确报告，而**绝不自动重试、绝不糊弄过关**——最终是否接受，永远由你
拍板。

> **你的收益：** 语速失控、口型错乱、角色穿帮、画面塞字幕等典型 AI 翻车，被系统
> 在你看到之前就大量拦下。

### 三、会「讲故事」的旁白与嵌套寓言

旁白不一定是看不见的播音员。爷爷、父母、老师或主角都可以先在画内和人对话，再用
**同一个声音**自然转为画外讲述；当他讲起一个嵌套寓言时：

- 画面只呈现寓言里的角色和场景，**讲述者不会错误地出现在画面中**（也不会以肖像、
  倒影、剪影等形式乱入）；
- 讲述用的一直是那个已确定的声音，不会中途换人；
- 寓言角色开口时讲述暂停，只有寓言角色的嘴在动；
- 讲完回到现实时，原来的场景、位置、道具和声音都会恢复。

> **你的收益：** 像「爷爷讲了一个故事」这种嵌套叙事，能被正确、连贯地拍出来，
> 而不是把讲述者和故事角色混成一锅。

### 四、自动编辑（把片段自动剪成完整成片）

你逐段接受的片段，会被系统**自动剪辑成一条连贯、干净的完整成片**——接缝、转场、
声音衔接、片尾收音全部替你处理好，你**不用打开任何剪辑软件、也不用懂剪辑**：

| 能力           | 说明                                                         |
| :------------- | :----------------------------------------------------------- |
| 自动拼接时间线 | 按剧本与分镜的权威顺序，把每段已接受的片段依次拼成一条完整时间线 |
| 智能接缝与转场 | 在片段衔接处自动决定并执行硬切、叠化或淡入淡出，衔接自然不跳戏 |
| 音画自动对齐   | 每段生成后立即按分镜窗口对齐 ElevenLabs 自然短语；环境与动作声只来自 Seedance 原生音轨，不改视频帧 |
| 去除 AI 瑕疵   | 自动裁掉回放尾帧、卡顿冻结帧、重复动作、多余画面和截断语音   |
| 有界画面顺滑   | 只做有限的亮度 / 对比 / 色彩技术归一化，绝不改动人物、台词与口型 |

> 全程只在你**已接受的片段**上做**无损、可逆**的编辑，绝不偷偷改动或替换原始片段；
> 遇到拿不准的接缝会停下来让你看，而不是硬糊过去。

> **你的收益：** 不用会剪辑，也能把一堆片段自动剪成一条干净、连贯、带同步声音和
> 精确字幕的成片。
